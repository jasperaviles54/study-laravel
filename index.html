Welcome

This is your hands-on Laravel study lab. It's built for someone starting from zero — no PHP, no frameworks. Everything you need to learn is here, in order — and it ends by having you build a real Laravel app on your own machine.

How it works

  1. Read the concept on each lesson page.
  2. Study the code example carefully — read every line.
  3. Try the exercise, then hit Check my answer — it analyzes your input and tells you what to fix before revealing the reference solution.
  4. Test yourself on the Quizzes page — pick a module to take its exam paper, answer every question, then Submit to see your score, the correct answers, and explanations.
  5. Mark complete only when you genuinely understand it.

The path

  • Module 1 — PHP Foundations: The language Laravel is built on.
  • Module 2 — Web & Database Basics: What a web framework actually does.
  • Module 3 — Laravel Core: Routing, controllers, Blade, Eloquent, validation, auth.
  • Module 4 — Debug Challenges: Broken code to fix from memory.
  • Module 5 — Build It: A guided build-along — create a real Laravel blog on your own machine, end to end.
